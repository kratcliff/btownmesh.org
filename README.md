# btownmesh.org

This is the web source code for [the home page of btownmesh.org](https://btownmesh.org/), the Meshtastic user group local to the Bloomington. Indiana, USA area.

## Contributing

Pull requests are welcome for content and design improvements.
See the [GitHub repo](https://github.com/kratcliff/btownmesh.org) for details.

This site uses Quarto to render. Download [Quarto](https://quarto.org) to build locally if you want to edit it yourself.
